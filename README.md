# Canva Element Grabber & Inserter (v2.0)

A Chrome Extension that lets you inspect and grab any graphic, shape, or photo directly from Canva's sidebar and drop it onto your canvas page.

---

## ✨ Features

- **🟢 Neon Green Inspector (`Alt + G`)**: Hovering over any element in Canva's sidebar highlights that exact element and turns your cursor into a neon green crosshair.
- **🎯 Precision Single-Tile Detection**: Captures the exact shape (Triangles, Polygons, Lines) or image you click, ignoring Crown and Three-dots UI badges.
- **⚡ Single-Drop Canvas Insertion**: Drops cleanly onto your design artboard without inserting duplicate copies.
- **🖼️ Live "Selected Element" Card in Popup**: Opening the extension popup displays the selected graphic live with one-click insertion and download.
- **📦 Floating Screen Tray**: An on-screen tray lets you drag and drop any captured graphic directly onto the canvas with your mouse.

---

## 🛠️ How to Install in Chrome

1. Open Google Chrome and go to:
   ```
   chrome://extensions/
   ```
2. Enable **Developer mode** (top-right toggle).
3. Click **"Load unpacked"** (top-left button).
4. Select this directory:
   ```
   T:\PROJECT\canva\canva-element-grabber
   ```
5. Switch to Canva and refresh the page.
6. Press **`Alt + G`** or click **Inspect** on the floating bar!
